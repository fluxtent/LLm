# Legacy Archive

This directory contains the retired TinyTransformer/BPE codepath that previously powered MedBrief AI.

Contents:

- `scripts/`: Archived Python scripts for the old tokenizer, model, training, generation, and Flask-based APIs.
- `artifacts/`: Legacy weights, vocab files, and generated outputs.
- `checkpoints/`: Historical training checkpoints.

These files are kept for reference and comparison only. They are not part of the production serving or training path.
